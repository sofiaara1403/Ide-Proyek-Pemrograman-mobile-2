EVORA ~ Your moments, beautifully organized
Personal Event Discovery & Digital Ticket App

📱 Overview
   EVORA adalah aplikasi mobile personal yang dirancang untuk membantu pengguna menemukan, mengelola, dan menyimpan event yang mereka ikuti dalam satu platform. Aplikasi ini menyediakan informasi event secara ringkas serta tiket digital berbasis QR Code sebagai bukti pendaftaran.
  EVORA dikembangkan sebagai tugas individu mata kuliah Pemrograman Mobile menggunakan Visual Studio, dengan fokus pada desain modern, alur aplikasi yang intuitif, serta pengelolaan data yang terstruktur.

💡 Background
   Banyak event kampus dan komunitas masih dikelola secara terpisah, sehingga peserta kesulitan dalam menyimpan informasi dan tiket acara. EVORA hadir sebagai solusi mobile sederhana untuk memusatkan seluruh aktivitas event pengguna.

🎯 Objectives
- Mengembangkan aplikasi mobile menggunakan Visual Studio
- Menerapkan konsep CRUD pada aplikasi mobile
- Mengimplementasikan arsitektur MVVM
- Membuat tiket digital berbasis QR Code
- Menghasilkan aplikasi mobile yang fungsional dan user-friendly

✨ Key Features
🔍 Event Discovery
Menampilkan daftar event yang tersedia
📝 Event Registration
Pendaftaran event langsung melalui aplikasi
🎫 Digital Ticket
Tiket digital berbentuk QR Code
🕒 Event History
Riwayat event yang pernah diikuti
🔔 Local Reminder
Pengingat jadwal event
👤 User Profile
Informasi dan preferensi pengguna

🧩 Application Scope
Aplikasi bersifat single user
Data event menggunakan dummy / local data
Tidak terdapat pembayaran online
Digunakan untuk keperluan akademik

☠️App Architecture
EVORA menggunakan arsitektur Model-View-ViewModel (MVVM) untuk memisahkan logika aplikasi dengan tampilan antarmuka, sehingga kode lebih terstruktur dan mudah dikembangkan.
